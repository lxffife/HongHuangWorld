# 酆都天城总体规划（第一版）

状态：城市空间规划基线 / 示意图阶段
对应目录：`scripts/world_map_catalog.gd`

## 1. 城市定位

酆都天城是冥界最大常住城市、阴司行政司法中心，也是玩家在冥界前中期的主要社交、交易、任务与生活枢纽。它不是一座普通鬼城，而是一座拥有皇城、官署、居民区、商业区、军事区、交通枢纽和完整城防体系的超大型古代都城。

酆都大帝主持城市行政；后土娘娘是幽冥本源与轮回法则的最高神位，不直接处理日常城市政务。

## 2. 城市空间结构

采用“皇城居中、官署分列、生活商业成区、四门连通远域”的布局：

- 中央核心：酆都皇城。
- 北部核心：皇城与北天门之间保留仪典、议政和核心禁区空间。
- 西侧官署：十王府、鬼籍司、阴兵大营。
- 东侧官署：判官司、功过司、引魂驿站。
- 南部核心：轮回司，连接南幽门与忘川方向。
- 东南生活商业：万魂鬼市。
- 西南生活区：万家魂坊。
- 城防：环城护城河、厚重城墙、四方城门、城门守将与城防驻军。

## 3. 九大功能区与四方城门

| 功能区/门户 | 主要职能 | 主要玩法 |
|---|---|---|
| 酆都皇城 | 阴司最高行政中枢 | 主线、政务、重要剧情 |
| 十王府 | 十殿审判与刑狱协调 | 审判、功过、地狱任务 |
| 判官司 | 案卷复核与司法文书 | 调查、审案、悬赏 |
| 鬼籍司 | 亡魂身份与鬼籍登记 | 新手引导、身份、档案 |
| 功过司 | 功德、罪业与因果记录 | 声望、因果委托 |
| 轮回司 | 轮回流程和转生文牒 | 转生、忘川任务 |
| 万魂鬼市 | 交易、拍卖、情报 | 玩家经济、社交 |
| 万家魂坊 | 居住、工匠和生活服务 | 家园、制作、社区 |
| 阴兵大营 | 城防、军需、巡逻 | 军事阵营、守城 |
| 引魂驿站 | 亡魂接引与远途交通 | 出生分流、跨区交通 |
| 北天门 | 北境与罗酆山方向 | 北境探索 |
| 南幽门 | 忘川与轮回渡口方向 | 亡魂流程与轮回 |
| 东玄门 | 幽冥荒原与远域官道 | 远征、血海方向交通 |
| 西冥门 | 军屯和古战场方向 | 边境巡防 |

“九大功能区”指九个核心城市治理与生活职能；阴兵大营和引魂驿站属于军事/交通专门设施，四方城门属于城市门户设施。它们在规划图中均独立标注。

## 4. 城市交通与防御

- 一条南北主轴连接北天门、皇城、轮回司和南幽门。
- 一条东西主轴连接西冥门、中央官署与东玄门。
- 次级官道连接十王府、判官司、鬼籍司、功过司、鬼市、居民区和驿站。
- 护城河与城墙形成连续外环；四门是常规出入节点。
- 城门并非随时无条件开放：服务端未来应依据任务、阵营、通缉状态、剧情阶段和城市事件决定通行权限。

## 5. 规划图坐标约定

- `FENGDU_CITY_PLAN` 使用 `schematic_city` 示意坐标。
- `wall_size`、`moat_size`、各区 `position/size` 仅用于 UI 排版，不是米制尺寸。
- 示意图中的道路只表达城市功能区之间的规划关系。
- 不能将示意尺寸用于 3D 地形生成、寻路、碰撞、服务端移动或实际城市面积推算。
- 未来需要另行制定真实世界坐标、分区实例、区块加载范围、建筑占地和道路宽度。

## 6. 从规划图到可玩城市的建设顺序

1. 建立城市灰盒：城墙、四门、主轴道路和各区占位。
2. 验证角色移动尺度、城门通行、视线遮挡和城区导航。
3. 建立城市服务交互：鬼籍、任务、商店、拍卖、生活技能、驿站。
4. 逐区补充建筑模块、NPC、环境声与夜间照明。
5. 将城市分区和入口接入服务端权威区域/权限数据。
6. 最后进行装饰、美术细化与性能优化。

当前仅完成目录数据与可交互示意规划图；尚未创建真实 3D 巨城、NPC 服务逻辑、城门权限或服务端分区。不得将规划图称为已完成的游戏城市。
