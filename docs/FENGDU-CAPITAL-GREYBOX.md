# 酆都天城 3D 灰盒原型

状态：独立可运行的 3D 灰盒漫游场景
场景：`scenes/experiments/FengduCapitalGreybox.tscn`
脚本：`scripts/experiments/fengdu_capital_greybox.gd`

## 1. 本阶段目标

把酆都城市规划图首次转换为可行走的三维空间，用于验证城市尺度、城墙高度、城门通行、道路宽度和皇城远景关系。该场景是独立实验，不替换线上世界场景，不改动正式玩家网络控制器，也不改变服务端世界边界。

## 2. 灰盒尺度

| 项目 | 当前原型尺寸 |
|---|---:|
| 城墙外轮廓宽度 | 1,900 m |
| 城墙外轮廓纵深 | 1,475 m |
| 护城河宽度 | 60 m |
| 城墙高度 | 54 m |
| 城墙厚度 | 18 m |
| 城门净开口目标 | 112 m |
| 南北主御道宽度 | 52 m |
| 东西主干道宽度 | 52 m |
| 城区位置映射 | 城市规划示意坐标 × 2.5 |

以上是本次灰盒的临时游戏尺度，不是最终世界设定的不可变数值。未来要根据玩家移动速度、建筑内部空间、视距、性能与服务器分区进一步校准。

## 3. 当前已生成的空间

- 大型地面基底与环城护城河。
- 四面城墙、四角瞭望塔。
- 北天门、南幽门、东玄门、西冥门的门楼灰盒与跨河桥面。
- 南北主御道、东西主干道及部分次级道路。
- 皇城、十王府、判官司、鬼籍司、功过司、巡城司、轮回司、万魂鬼市、万家魂坊。
- 阴兵大营与引魂驿站。
- 主殿、侧殿、商铺、营房等简单体块。
- 从南门方向观察中央皇城轮廓的远景标识。
- 本地漫游角色、碰撞、跳跃和简易 HUD。

建筑目前全部由基础几何体构成，不是最终美术模型。

## 4. 如何运行

1. 在 Godot 4 编辑器中打开 `Client/HongHuangClient/project.godot`。
2. 在文件系统中打开 `res://scenes/experiments/FengduCapitalGreybox.tscn`。
3. 使用“运行当前场景”（F6），不要将它设为项目主场景。
4. 首次点击场景窗口捕获鼠标。

控制：
- W/A/S/D：移动。
- 鼠标：观察方向。
- Shift：奔跑。
- Space：跳跃。
- Esc：释放鼠标；点击窗口重新捕获。

## 5. 当前限制

- 这是单机本地灰盒，不连接玩家身份、聊天、游戏世界服务或服务器权威移动。
- 还没有 NavMesh、NPC、商店、任务、室内空间、门禁逻辑和跨区传送。
- 城区是若干基础体块，尚无完整街巷、屋顶细节、建筑内部和生活动线。
- 护城河目前是静态水面，不具备水体物理和游泳机制。
- 尚未完成 Godot 编辑器解析、运行和性能实测；必须在本地 Godot 4 编辑器中运行当前场景后，才能确认运行时结果。
- 当前项目未锁定确切 Godot 4 小版本；不要在未核实版本兼容性前引入 Terrain3D 等外部插件。

## 6. 下一轮验收重点

1. 从南门步行进入，检查门洞、桥面和城墙碰撞是否合理。
2. 沿中轴道路前进，确认皇城远景可读且不会被浓雾完全遮挡。
3. 检查九大功能区之间是否有足够步行空间、道路是否穿过建筑。
4. 记录步行从南门到皇城的耗时，按实际体验调整城市比例。
5. 再把灰盒模块化为可复用城墙、门楼、宫殿、官署、商铺和民居场景。
