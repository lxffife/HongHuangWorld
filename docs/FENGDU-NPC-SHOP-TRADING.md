# 酆都 NPC 商铺交易接入

## 本次范围

酆都商铺不再只是数据库中的目录与后端接口：玩家与指定 NPC 完成交互后，可以从 NPC 对话面板打开对应摊位，读取商品、价格、货币和库存，并按堆叠上限选择数量购买。购买结果由中心服返回并显示。

## NPC 与商铺绑定

| NPC | 商铺 | 类型 |
|---|---|---|
| 铁砧老周（`fengdu_blacksmith`） | `fengdu_weapon_shop` | 兵器、防具 |
| 孟婆（`fengdu_mengpo`） | `fengdu_elixir_shop` | 恢复丹药 |
| 魂灯摊主（`fengdu_ghost_market_vendor_east`） | `fengdu_talisman_shop` | 镇魂符箓 |
| 纸钱铺掌柜（`fengdu_ghost_market_vendor_west`） | `fengdu_general_shop` | 常见材料 |
| 镇祟校尉（`fengdu_trial_master`） | `fengdu_formation_shop` | 阵旗材料 |

绑定由迁移 `000079_bind_fengdu_shops_to_npcs` 建立，NPC 与商铺必须处于同一世界。

## 交易规则

- 客户端只提交商品 ID、数量和 UUID 请求编号，不提交价格、余额、角色位置或库存。
- 中心服从当前登录账户解析存活角色和活动世界会话。
- 购买时中心服读取角色数据库坐标，并验证角色处于绑定 NPC 的交互半径内。
- 商铺、NPC、商品和货币必须启用且属于当前世界。
- 扣款、有限库存扣减、背包发放、购买事件记录处于同一数据库事务；任一步失败都会回滚。
- 请求编号用于幂等重试；相同编号不能被复用于不同商品或数量。
- 背包容量、堆叠上限、余额不足、库存不足均由中心服拒绝。

## 第二批商品目录（000080）

- 纸钱铺：黄泉纸钱、引魂香、鬼骨粉、魂灯灯油。
- 魂灯符箓铺：黄泉纸钱、引魂香、缚魂丝、凝阴砂。
- 阵材铺：凝阴砂、缚魂丝、鬼骨粉。
- 黄泉丹药坊：温魂丹、凝雾丹，以及原有小还元丹、小聚灵丹。
- 凝阴砂、缚魂丝等商品使用有限库存；中心服事务扣减库存，并按补货周期惰性恢复库存，不需要额外定时任务。常见物资每 30 分钟补充，稀有材料每 60 分钟补充，始终不超过库存上限。
- 温魂丹与凝雾丹沿用已有消耗品使用流程，不会绕过 WorldServer 对在线角色生命/灵力的权威管理。

## 客户端操作

1. 靠近 NPC，按 F 交互。
2. 点击“打开鬼市摊位 · 查看商品”（其他已绑定商铺 NPC 也显示对应入口）。
3. 商品列表显示品质、分类、单价、货币与库存，并提供单件或批量购买数量选择。
4. 每件商品可按堆叠上限与当前有限库存选择 1、5、10、20、50 或 99 件；服务端仍会再次校验数量、余额、背包容量和库存。
5. 购买成功后立即刷新钱袋、背包、装备投影与摊位库存；在线角色使用丹药仍须走 WorldServer 的权威消耗品流程。

## 部署顺序

先应用此前依赖迁移（至少 000067、000073、000078），再依次应用 000079、000080 和 000081：

```bash
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 \
  -f Database/migrations/000079_bind_fengdu_shops_to_npcs.up.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 \
  -f Database/migrations/000080_fengdu_shop_catalog_expansion.up.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 \
  -f Database/migrations/000081_fengdu_shop_restock.up.sql
```

随后重新编译并重启 Backend。000079 回滚只解除 NPC 绑定列；000080 回滚会移除新增商铺关联并停用新物品定义，保留已产生的背包和历史交易引用；000081 回滚只移除自动补货配置，不改变当前库存。
