# 洪荒世界管理后台前端

技术栈：Vue 3、TypeScript、Vite、Element Plus。

## 本地开发

1. 确保 PostgreSQL 已启动，并按 `Deployment/migrate-database.ps1` 或对应 Linux 迁移流程执行 Game、Identity、Admin 数据库迁移；Game 数据库当前迁移至 `000047`。
2. 配置 `Deployment/.env` 中各服务独立数据库连接、内部服务密钥及后台超级管理员初始化信息。
3. 启动 Identity、Game API 和 Admin API。Admin API 默认监听 `127.0.0.1:8790`。
4. 在本目录执行 `npm install`，然后执行 `npm run dev`。
5. 使用浏览器打开 Vite 输出的本机地址。Vite 将 `/api`、`/health`、`/ready` 代理到本机 `127.0.0.1:8790`。

## 已接入模块

- **运营总览**：在线玩家数、启用世界数、正常节点数。
- **服务健康监控**：并行检查 Identity、Game、Chat、Admin 四个服务的 `/ready`，分别展示数据库就绪结果、响应耗时与最近检查时间。单服务故障仅标记对应服务，不把 Chat/Game 的运行状态耦合起来。
- **玩家管理**：账号搜索、在线玩家、玩家详情、封禁、解封、强制下线；详情展示当前肉身属性与修为、灵魂积累、五项来世资质、吞噬记录、稀有变异/融合、历世与转世记录、出生资质快照。
- **世界管理**：世界定义、实例列表、启用/停用世界。
- **服务器监控**：节点心跳、在线负载、恢复/排空/禁用节点。
- **怪物与掉落**：怪物模板、世界刷新点、物品目录、掉落概率配置。
- **配置版本历史**：历史快照查看、字段级差异预览、填写回滚原因后恢复历史版本。
- **操作审计**：查询管理员关键操作记录。
- **后台用户与权限**：后台用户创建、权限分配、本人密码修改。

复杂配置编辑器使用 JSON 编辑方式，保存时由后端执行字段校验、事务和权限检查。前端页面权限只用于显示控制，所有权限仍由 Admin API 服务端强制校验。

## 部署安全

生产环境应通过 HTTPS 反向代理访问管理后台；Admin API 默认绑定回环地址，不应直接暴露公网。不要将 `Deployment/.env` 或真实密钥提交到仓库。Identity、Game、Chat、Admin 应继续使用各自独立数据库与内部服务密钥。
