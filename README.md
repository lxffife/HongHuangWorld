# Godot 客户端

使用 Godot 4.x，优先 GDScript。客户端目前包含中心服登录、灵魂档案检查、世界列表、首次角色创建与世界入口票据申请流程。

## 运行

1. 使用 Godot 4.x 打开本目录中的 project.godot。
2. 启动中心服 API（默认 http://127.0.0.1:8787）。
3. 启动一个已注册且心跳正常的 WorldServer 节点，并确保该角色世界有 ready 实例。
4. 运行项目，在登录页输入账号、密码和中心服地址。

登录成功后客户端会读取灵魂档案；如果没有灵魂档案，会先创建灵魂档案；如果没有当前角色，则允许选择出生世界并创建第一世角色。随后申请一次性世界入口票据。若尚未注册可用世界服节点，中心服会返回 503，这是部署状态而非客户端登录故障。

## 当前边界

- 已实现：HTTP 登录、灵魂档案读取/创建、世界列表、角色创建、世界入口票据申请。
- 已实现：GDScript 协议 v1 帧编码、ClientHello 编码、帧头校验/解码。
- 尚未实现：Godot 到自定义 C++ ENet 帧协议的原生传输适配器、ServerWelcome 实际收包、角色场景加载与多人同步。
- 不要使用 Godot 内置 MultiplayerAPI 直接连接当前 C++ 服务端；两者应用层协议不同。

## 网络协议

协议实现见 scripts/protocol_codec.gd。固定帧头 12 字节，HHW1 magic，版本 1，大端序；ClientHello 包含 uint16 长度前缀的 ticket 和 client_build。
